## Portfolio architecture
- Keep this portfolio in the index route with in-page navigation; the approved design is a single scrolling page.
- Define visual tokens and reusable portfolio styles in src/styles.css so presentation stays consistent.
- Use bundled editorial project imagery as illustrative covers, not screenshots of client applications.
