# Ajay Sharma Portfolio

## Goal
Create a polished single-page developer portfolio from the supplied resume, with a clear distinction that all featured projects are professional client work completed during employment.

## What I’ll build
- A concise opening section with Ajay’s role, experience summary, contact links, and availability-focused call to action.
- A professional experience section for HawksCode Technologies with measurable highlights.
- A selected professional work section for Thrive Black Car, Mortgage House, and Tohaa Design, including location, responsibilities, and technology used.
- A scannable technical skills section and education details.
- A compact navigation and footer with direct email, phone, LinkedIn, and GitHub links.

## Visual direction
- Editorial, developer-focused design with crisp typography, dark ink surfaces, warm neutral canvas, and a restrained lime accent.
- Spacious desktop composition with a strong mobile layout, subtle motion, and no unnecessary effects or complicated interactions.
- All styling will use a reusable semantic design system in Tailwind CSS.

## Technical details
- Implement as the existing React/TanStack Start index page using Tailwind CSS v4.
- Use Lucide icons and existing design components where appropriate.
- Add page-specific title, description, Open Graph, and Twitter metadata.
- Verify the production build and check desktop and mobile rendering in the browser.
